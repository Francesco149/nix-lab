184 # `video` is temporarily disabled (2026-06-15): the updated nixpkgs llama-cpp
185 # moved its web UI to tools/ui, which the pinned April llama.cpp commit behind
186 # the Cobdog video patch lacks, so llama-cpp-cuda-video's npm-deps build fails
187 # (`pushd: tools/ui: No such file or directory`). Drop it from this removeAttrs
188 # once src.rev + the video patch are bumped to a commit matching the new
189 # layout. removeAttrs also keeps Nix from forcing (building) the broken derivation.
190 #
191 # `embed` is disabled (2026-06-15) to FREE THE 3080 for the interactive GPU
192 # sandbox (Godot/OpenGL over Sunshine; the 3080 is shared into containers via
193 # nvidia-container-toolkit — see hosts/lame/lame.nix). The lab isn't using
194 # embeddings right now. Re-enable by dropping "embed" here when the 3080 is wanted
195 # for embeddings again (note: open-webui RAG embeddings depend on this service).
196 #
197 # `vulkan` is disabled (2026-06-16) to FREE THE 7800XT for haruness harness dev,
198 # which spins up its own llama.cpp servers on that card (see ../../WORKDOC.md).
199 # With all three removed the llama stack is fully off on lame. Re-enable by
200 # dropping "vulkan" here when the lab wants its shared llama endpoint back.
